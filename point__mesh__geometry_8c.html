resource_result_t point_mesh_geometry_initialize_from_vertices ( const char *  name_,
size_t  vertex_count_,
const point_vertex_t *  vertices_,
point_mesh_geometry_t *  geometry_ 
)

引数で頂点配列を与えてpoint_mesh_geometry_t構造体インスタンスを初期化する

Note
point_mesh_geometry_tの内部リソースはpoint_mesh_geometryが所有するため、一度初期化したあと、destroyまたはdeinitializeをせずに再初期化するのは禁止する。これを行った場合、RESOURCE_BAD_OPERATIONを返す
geometry_にvertices_をdeep copyする。vertices_の所有権は呼び出し側にある
失敗時にはgeometry_の内部状態は不変
Parameters
[in]name_ジオメトリ名称文字列
[in]vertex_count_頂点配列の配列要素数で、点の数を指定する
[in]vertices_頂点配列
[in,out]geometry_point_mesh_geometry_t構造体インスタンスへのポインタ
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • name_ == NULL
  • name_が空文字列
  • vertex_count_ == 0
  • vertices_ == NULL
  • geometry_ == NULL
RESOURCE_BAD_OPERATION以下のいずれか
  • geometry_ が初期状態ではない
  • メモリシステムが未初期化
RESOURCE_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RESOURCE_NO_MEMORYメモリ確保失敗
RESOURCE_OVERFLOW以下のいずれか
  • ジオメトリ名称文字列処理でoverflowが発生
  • 頂点配列確保サイズの計算でoverflowが発生
RESOURCE_SUCCESS処理に成功し、正常終了
