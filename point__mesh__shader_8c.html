)

ポイント描画用シェーダーリソースインスタンスのメモリを確保し初期化する

以下の処理を行う

  • out_point_mesh_shader_自身のリソース確保
  • シェーダーソースのコンパイル
  • シェーダーモジュールのリンク
  • ポイント描画用シェーダーが扱うモデル行列のLocation取得
  • ポイント描画用シェーダーが扱うビュー行列のLocation取得
  • ポイント描画用シェーダーが扱うプロジェクション行列のLocation取得
Parameters
[in]backend_context_レンダラーバックエンドコンテキストへのポインタ
[in]file_path_シェーダーソース格納ファイルパス(文字列の最後を'/'にすること)
[in]name_シェーダーソースファイル名称(拡張子は含まない)
[out]out_point_mesh_shader_リソース確保対象ポイント描画用シェーダーリソースへのダブルポインタ
Return values
RENDERER_INVALID_ARGUMENT以下のいずれか
  • file_path_ == NULL
  • name_ == NULL
  • backend_context_ == NULL
  • out_point_mesh_shader_ == NULL
  • *out_point_mesh_shader_ != NULL
RENDERER_NO_MEMORYメモリ確保失敗
RENDERER_LIMIT_EXCEEDEDメモリシステムのメモリ使用量範囲上限超過
RENDERER_RUNTIME_ERROR以下のいずれか
  • 計算過程でオーバーフロー発生(文字列長さ異常)
  • ユニフォーム変数のLocation取得に失敗
RENDERER_DATA_CORRUPTED内部データ破損が発生
RENDERER_BAD_OPERATION以下のいずれか
  • レンダラーバックエンドが未初期化
  • シェーダーソースが既にコンパイル済み
  • シェーダーモジュールが既にリンク済み
  • メモリシステム未初期化
RENDERER_SHADER_COMPILE_ERROR以下のいずれか
  • シェーダーモジュールのGPU側リソース確保に失敗
  • シェーダーソースのコンパイルに失敗
RENDERER_SHADER_LINK_ERRORシェーダーモジュールのリンクに失敗
RENDERER_SUCCESS処理に成功し、正常終了

ポイント描画用シェーダーリソースインスタンスが保持するリソースと、自身のメモリを解放する

Note
  • 有効なbackend_context_と有効なpoint_mesh_shader_が渡された場合、破棄後に*point_mesh_shader_はNULLに設定される
  • 引数が無効の場合にはWARNINGメッセージを出力し、何もしない
  • 2重デストロイ許可
  • GPU側のシェーダープログラムリソースも破棄される
Parameters
[in]backend_context_Renderer Backendコンテキスト構造体インスタンスへのポインタ
[in,out]point_mesh_shader_破棄対象ポイント描画用シェーダーリソースインスタンスへのダブルポインタ

ポイント描画用シェーダー用のバーテックスバッファを生成する

Note
バーテックスバッファ構成
  • layout 0: 頂点座標。float x 3。
  • layout 1: 色情報。uint8_t x 4 のRGBA, OpenGL側で0.0〜1.0に正規化され、shaderではvec4として扱われる。
Parameters
[in]backend_context_Renderer Backendコンテキスト構造体インスタンスへのポインタ
[in,out]point_mesh_shader_バーテックスバッファ生成対象ポイント描画用シェーダーリソースインスタンスへのポインタ
[in]point_buffer_usage_頂点情報バッファ使用用途(DYNAMIC / STATIC)
[in]color_buffer_usage_色情報バッファ使用用途(DYNAMIC / STATIC)
[in]point_buffer_size_頂点情報バーテックスバッファサイズ(byte)
[in]color_buffer_size_色情報バーテックスバッファサイズ(byte)
Return values
RENDERER_INVALID_ARGUMENT以下のいずれか
  • backend_context_ == NULL
  • point_mesh_shader_ == NULL
  • point_buffer_size_ == 0
  • color_buffer_size_ == 0
RENDERER_BAD_OPERATION以下のいずれか
  • backend_context_が未初期化
  • point_mesh_shader_->point_vao != NULL
  • point_mesh_shader_->point_vbo != NULL
  • point_mesh_shader_->color_vbo != NULL
  • point_mesh_shader_->point_current_buffer_offset != 0
  • point_mesh_shader_->color_current_buffer_offset != 0
  • point_mesh_shader_->current_vertex_count != 0
  • メモリシステム未初期化
RENDERER_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RENDERER_NO_MEMORYメモリ確保失敗
RENDERER_RUNTIME_ERRORpoint_buffer_usage_ / color_buffer_usage_またはpoint_buffer_size_ / color_buffer_size_が規定値外
RENDERER_SUCCESS処理に成功し、正常終了
