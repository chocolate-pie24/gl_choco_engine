◆ flight_camera_command_execute()

application_result_t flight_camera_command_execute ( float  speed_,
float  delta_time_,
command_status_flight_camera_t *  command_status_,

)

フライトカメラ制御コマンド実行用構造体インスタンス配列のフィールド状態に基づいて制御を実行する

Note
  • 制御が実行され、カメラが動いた場合はcamera_構造体フィールドが更新される
  • 複数のコマンドを実行する場合に、コマンド実行に成功したのち、別のコマンド実行に失敗した場合は実行結果コードがエラーになり、かつ、out_view_updated_はtrueになる
Parameters
[in]speed_カメラ移動速度
[in]delta_time_カメラ移動時間
[in]command_status_フライトカメラ制御コマンド実行用構造体インスタンス配列
[in,out]camera_制御対象カメラ構造体インスタンスへのポインタ
[out]out_view_updated_フライトカメラが動いたことの通知フラグへのポインタ(true: カメラ動作あり / false: カメラ動作なし)
Return values
APPLICATION_INVALID_ARGUMENT以下のいずれか
  • camera_ == NULL
  • command_status_ == NULL
  • out_view_updated_ == NULL
APPLICATION_RUNTIME_ERROR以下のいずれか
  • カメラ位置の取得,更新に失敗
  • 逆行列計算に失敗
APPLICATION_SUCCESS処理に成功し、正常終了
