◆ lit_mesh_shader_create()

renderer_result_t lit_mesh_shader_create ( renderer_backend_context_t *  backend_context_,
const char *  file_path_,
const char *  name_,
lit_mesh_shader_t **  out_lit_mesh_shader_ 
)

lit_meshシェーダーリソースインスタンスのメモリを確保し初期化する

以下の処理を行う

  • out_lit_mesh_shader_自身のリソース確保
  • シェーダーソースのコンパイル
  • シェーダーモジュールのリンク
  • lit_meshシェーダーが扱うモデル行列のLocation取得
  • lit_meshシェーダーが扱うビュー行列のLocation取得
  • lit_meshシェーダーが扱うプロジェクション行列のLocation取得
Parameters
[in]backend_context_レンダラーバックエンドコンテキストへのポインタ
[in]file_path_シェーダーソース格納ファイルパス(文字列の最後を'/'にすること)
[in]name_シェーダーソースファイル名称(拡張子は含まない)
[out]out_lit_mesh_shader_リソース確保対象lit_meshシェーダーリソースへのダブルポインタ
Return values
RENDERER_INVALID_ARGUMENT以下のいずれか
  • file_path_ == NULL
  • name_ == NULL
  • backend_context_ == NULL
  • out_lit_mesh_shader_ == NULL
  • *out_lit_mesh_shader_ != NULL
RENDERER_NO_MEMORYメモリ確保失敗
RENDERER_LIMIT_EXCEEDEDメモリシステムのメモリ使用量範囲上限超過
RENDERER_RUNTIME_ERROR以下のいずれか
  • 計算過程でオーバーフロー発生(文字列長さ異常)
  • ユニフォーム変数のLocation取得に失敗
RENDERER_DATA_CORRUPTED内部データ破損が発生
RENDERER_BAD_OPERATION以下のいずれか
  • レンダラーバックエンドが未初期化
  • シェーダーソースが既にコンパイル済み
  • シェーダーモジュールが既にリンク済み
  • メモリシステム未初期化
RENDERER_SHADER_COMPILE_ERROR以下のいずれか
  • シェーダーモジュールのGPU側リソース確保に失敗
  • シェーダーソースのコンパイルに失敗
RENDERER_SHADER_LINK_ERRORシェーダーモジュールのリンクに失敗
RENDERER_SUCCESS処理に成功し、正常終了

◆ lit_mesh_shader_destroy()

lit_mesh_shader_t **  lit_mesh_shader_

lit_meshシェーダーリソースインスタンスが保持するリソースと、自身のメモリを解放する

Note
  • 有効なbackend_context_と有効なlit_mesh_shader_が渡された場合、破棄後に*lit_mesh_shader_はNULLに設定される
  • 引数が無効の場合はWARNINGを出力し、何もしない
  • 2重デストロイ許可
  • GPU側のシェーダープログラムリソースも破棄される
Parameters
[in]backend_context_Renderer Backendコンテキスト構造体インスタンスへのポインタ
[in,out]lit_mesh_shader_破棄対象lit_meshシェーダーリソースインスタンスへのダブルポインタ
