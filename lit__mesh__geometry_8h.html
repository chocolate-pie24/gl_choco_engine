◆ lit_mesh_geometry_initialize()

resource_result_t lit_mesh_geometry_initialize ( const char *  name_,
size_t  vertex_count_,
const point_normal_vertex_t *  vertices_,
lit_mesh_geometry_t *  geometry_ 
)

引数で頂点配列を与えてlit_mesh_geometry_t構造体インスタンスを初期化する

Note
lit_mesh_geometry_tの内部リソースはlit_mesh_geometryが所有するため、一度初期化したあと、destroyまたはdeinitializeをせずに再初期化するのは禁止する。これを行った場合、RESOURCE_BAD_OPERATIONを返す
geometry_にvertices_をdeep copyする。vertices_の所有権は呼び出し側にある
失敗時にはgeometry_の内部状態は不変
Parameters
[in]name_ジオメトリ名称文字列
[in]vertex_count_頂点配列の配列要素数で、三角形の頂点の数を三角形ごとに指定する(三角形の数 = vertex_count_ / 3となる)
[in]vertices_頂点配列
[in,out]geometry_lit_mesh_geometry_t構造体インスタンスへのポインタ
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • name_ == NULL
  • name_が空文字列
  • vertex_count_ == 0
  • vertices_ == NULL
  • geometry_ == NULL
  • vertex_count_が3の倍数ではない
RESOURCE_BAD_OPERATION以下のいずれか
  • geometry_がすでに初期化済みで内部状態が0, NULL以外
  • メモリシステムが未初期化
RESOURCE_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RESOURCE_NO_MEMORYメモリ確保失敗
RESOURCE_OVERFLOW以下のいずれか
  • ジオメトリ名称文字列処理でoverflowが発生
  • 頂点配列確保サイズの計算でoverflowが発生
RESOURCE_SUCCESS処理に成功し、正常終了
