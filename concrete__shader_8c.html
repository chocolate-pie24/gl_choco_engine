Parameters
[in]shader_type_シェーダー種別指定値
[in]shader_source_シェーダーソース
[in,out]shader_handle_シェーダー関連リソース管理構造体インスタンスへのポインタ
Return values
RENDERER_BACKEND_INVALID_ARGUMENT以下のいずれか
  • shader_source_ == NULL
  • shader_handle_ == NULL
  • shader_type_が規定値外
RENDERER_BACKEND_BAD_OPERATION以下のいずれか
  • 指定したシェーダー種別はすでにコンパイル済み
  • シェーダープログラムがすでにリンク済み
  • メモリシステム未初期化
RENDERER_BACKEND_SHADER_COMPILE_ERRORシェーダーソースコンパイルエラー
RENDERER_BACKEND_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RENDERER_BACKEND_NO_MEMORYメモリ確保失敗
RENDERER_BACKEND_SUCCESS処理に成功し、正常終了
