Detailed Description

ui_meshシェーダーが描画する形状データのCPU側リソースを操作するモジュールAPIの定義

Author
chocolate-pie24
Note
ui_mesh_shader: 2D矩形領域にテクスチャを貼った描画を行う, 描画単位は矩形領域ごとに描画する
ui_mesh_geometryは矩形領域のテクスチャuv座標、矩形領域座標のみを保持する

引数で頂点配列を与えてui_mesh_geometry_t構造体インスタンスを初期化する

Note
ui_mesh_geometry_tの内部リソースはui_mesh_geometryが所有するため、一度初期化したあと、destroyまたはdeinitializeをせずに再初期化することは禁止する。これを行った場合、RESOURCE_BAD_OPERATIONを返す
geometry_にvertices_をdeep copyする。vertices_の所有権は呼び出し側にある
失敗時にはgeometry_の内部状態は不変
vertex_count_は6固定なので引数指定は不要だが、当面は残す
Parameters
[in]name_ジオメトリ名称文字列
[in]vertex_count_6固定(頂点配列の配列要素数で、矩形領域を構成する2枚の三角形の頂点数)
[in]vertices_頂点配列
[in,out]geometry_ui_mesh_geometry_t構造体インスタンスへのポインタ
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • name_ == NULL
  • name_が空文字列
  • vertices_ == NULL
  • geometry_ == NULL
  • vertex_count_が6ではない
RESOURCE_BAD_OPERATION以下のいずれか
  • geometry_ が初期状態ではない
  • メモリシステムが未初期化
RESOURCE_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RESOURCE_NO_MEMORYメモリ確保失敗
RESOURCE_OVERFLOW以下のいずれか
  • ジオメトリ名称文字列処理でoverflowが発生
  • 頂点配列確保サイズの計算でoverflowが発生
RESOURCE_SUCCESS処理に成功し、正常終了
