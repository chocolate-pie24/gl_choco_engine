Detailed Description

STLファイルのロード処理を行うAPIの実装

Author
chocolate-pie24

以下のSTLファイルをサポートする

  • ASCII形式のSTL(BINARY形式は将来的にサポート予定)

  • ファイルに含まれる法線情報は[-1.0...1.0]の範囲に正規化されていること

◆ stl_loader_ascii_load()

resource_result_t stl_loader_ascii_load ( const char *  path_,
const char *  name_,
const char *  extension_,
stl_loader_t *  stl_loader_ 
)

ASCII形式のSTLファイルを読み込む

Note
ロード可能なSTLデータは法線情報が-1.0...1.0に正規化されている必要がある(されていない場合はRESOURCE_DATA_CORRUPTEDを返す)
失敗時にはstl_loader_の状態は不変
Parameters
[in]path_STLファイルが格納されているパス(最後は'/'が入っていること)
[in]name_STLファイル名(拡張子は含まない)
[in]extension_STLファイル拡張子('.'で始まること)
[in,out]stl_loader_stl_loader_t構造体インスタンスへのポインタ
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • path_ == NULL
  • name_ == NULL
  • extension_ == NULL
  • stl_loader_ == NULL
RESOURCE_BAD_OPERATION以下のいずれか
  • 0 != stl_loader_->vertex_count
  • stl_loader_->vertices != NULL
  • メモリシステム未初期化
RESOURCE_FILE_OPEN_ERRORSTLファイルオープン失敗
RESOURCE_UNDEFINED_ERRORファイル読み込み時に不明なエラーが発生
RESOURCE_DATA_CORRUPTED以下のいずれか
  • 内部データ破損
  • STLデータ不整合
  • 頂点情報、法線情報のパース失敗
  • 法線情報が[-1.0...1.0]の範囲外、またはNaN、Infが含まれる
  • 頂点情報にNaN、Infが含まれる
RESOURCE_LIMIT_EXCEEDEDメモリシステム使用可能範囲上限超過
RESOURCE_NO_MEMORYメモリ確保失敗
RESOURCE_OVERFLOW以下のいずれか
  • ファイルフルパス文字列が長すぎる
  • STLデータに格納されている頂点の数または法線の数がSIZE_MAXを超過
  • 頂点配列確保サイズの計算でoverflowが発生
RESOURCE_RUNTIME_ERROR以下のいずれか
  • 1回目の頂点数カウント結果と2回目の読み込み結果が一致しない(STLファイルが読み込み中に変更された可能性がある)
  • ファイル読み込みでエラー発生
RESOURCE_SUCCESS処理に成功し、正常終了

◆ stl_loader_destroy()

void stl_loader_destroy ( stl_loader_t **  stl_loader_)

stl_loader_が保有するリソースを解放し、自身のメモリを解放する

Note
本APIが成功した場合、stl_loader_はNULLとなり、再使用不可
2重destroyを許可
NULL != (*stl_loader_)->verticesかつ0 == (*stl_loader_)->vertex_countのように壊れたデータの場合には、verticesのメモリ解放サイズが不明であるため解放せず、verticesはリーク状態となる(この場合はエラーメッセージを出力する)
Parameters
[out]stl_loader_リソース解放対象stl_loader_t構造体インスタンスへのダブルポインタ
