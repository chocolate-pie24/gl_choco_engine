# GL CHOCO ENGINE (GLCE) APIリファレンス

GL CHOCO ENGINE (GLCE)は、ロボティクス、産業システム、組み込み周辺環境における可視化・デバッグ用途を主な対象とした、
軽量なC/OpenGLベースのレンダリングおよびアプリケーションフレームワークです。

本ドキュメントは、Doxygenによって生成されたGLCEのAPIリファレンスです。

## 対応環境

- macOS
- Linux
- FreeBSD

## グラフィックス環境

- OpenGL
- GLFW
- GLEW
