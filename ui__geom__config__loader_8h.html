◆ ui_geom_config_loader_load()

resource_result_t ui_geom_config_loader_load ( const char *  name_,
ui_geom_config_t *  out_config_ 
)

UI描画用ジオメトリコンフィグレーションファイルをロードし、設定値を取得する

Note
処理に失敗した場合、out_config_の状態は変更されない
Parameters
[in]name_設定値格納ファイル名(パス, 拡張子は含まない)
[out]out_config_設定値格納先ui_geom_config_t構造体インスタンスへのポインタ
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • name_ == NULL
  • out_config_ == NULL
RESOURCE_LIMIT_EXCEEDED以下のいずれか
  • メモリシステムのシステム使用可能範囲上限を超過
  • 一行に含まれる文字列が長すぎる
RESOURCE_NO_MEMORYメモリ割り当て失敗
RESOURCE_OVERFLOW以下のいずれか
  • フルパス文字列が長すぎる
  • コンフィグレーションファイルに含まれる行数が多すぎる
  • 読み込んだ設定値が規定値を超過
RESOURCE_DATA_CORRUPTED以下のいずれか
  • 処理過程において内部データ不整合が発生
  • コンフィグレーションファイルに規定とは異なる設定値が含まれる
RESOURCE_FILE_OPEN_ERRORコンフィグレーションファイルオープンエラー
RESOURCE_BAD_OPERATIONメモリシステム未初期化
RESOURCE_FILE_READ_ERROR読み込み中に実行時エラーが発生
RESOURCE_UNDEFINED_ERROR上記以外の不明なエラーが発生
RESOURCE_SUCCESS処理に成功し、正常終了
