Parameters
[in]registry_lit_mesh_geometry_registry_t構造体インスタンスへのポインタ

Return values

  • name_ == NULL
  • registry_ == NULL
  • out_geometry_id_ == NULL

RESOURCE_REGISTRY_BAD_OPERATIONregistry_内に名称name_のジオメトリが存在しない
RESOURCE_REGISTRY_SUCCESS処理に成功し、正常終了
