Detailed Description

BMPファイルのロード処理を行うAPIの実装

Author
chocolate-pie24

GLCEでは以下のBMPファイルをサポートする

  • 非圧縮BMPファイル
  • ピクセルのチャンネルカウントはRGB or RGBAのみ
  • 画像の高さがint16_tに収まること
  • 画像の幅がが0より大きく、かつint16_tに収まること

処理に失敗した場合、out引数は不変
Parameters
[in]fullpath_BMPファイルのフルパス
[in]file_header_FILEHEADER構造体インスタンスへのポインタ
[in,out]info_header_INFOHEADER構造体インスタンスへのポインタ
[in]stride_BMPファイルの各行のサイズ(byte)
[out]out_pixels_読み込んだピクセルデータの格納先(メモリは本関数内で確保する)
Return values
RESOURCE_INVALID_ARGUMENT以下のいずれか
  • fullpath_ == NULL
  • file_header_ == NULL
  • info_header_ == NULL
  • out_pixels_ == NULL
  • *out_pixels_ != NULL
  • stride_ == 0
RESOURCE_LIMIT_EXCEEDEDメモリシステムの使用可能範囲上限超過
RESOURCE_NO_MEMORYメモリ確保失敗
RESOURCE_BAD_OPERATIONメモリシステム未初期化
RESOURCE_FILE_OPEN_ERRORファイルオープン失敗
RESOURCE_UNDEFINED_ERROR未定義エラーが発生
RESOURCE_FILE_READ_ERRORピクセル読み込み失敗
RESOURCE_DATA_CORRUPTEDピクセル読み込みサイズ異常
RESOURCE_OVERFLOW計算過程でオーバーフロー発生
RESOURCE_SUCCESS処理に成功し、正常終了
